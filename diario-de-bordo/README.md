# Diário de Bordo · janela do colaborador

Site estático (GitHub Pages) que conversa direto com o Supabase.

- `index.html`: a página
- `app.js`: toda a lógica (login, tarefas, registro, compressão de fotos, sons)
- `estilo.css`: o visual
- `config.js`: **o único arquivo que você precisa editar** (endereço e chave pública do Supabase)

Como publicar: veja o `TUTORIAL.md` que veio no pacote.
